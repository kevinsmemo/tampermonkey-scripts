# YouTube Slides Extractor — Chrome Extension v0.3.5 (Cloud Alpha)

## 安裝與連接

1. 下載此分支 ZIP，解壓縮。停用舊 Tampermonkey 腳本（不要移除資料）。
2. 此測試版已內建專案 OAuth Client ID，不需要 setup.html 或個別設定。Chrome 的 chrome://extensions → 開發人員模式 → 載入未封裝項目 → 選 chrome-extension 資料夾。
3. 如果已載入舊 Alpha，直接覆蓋原擴充套件資料夾中的檔案並按重新載入；不要卸載以免清除離線資料。
4. 點擴充套件圖示或 YouTube 面板「Google Drive 設定」。新資料夾模式僅請求 drive.file；既有資料夾模式需完整 Drive scope 並輸入專用 YouTube Slides 資料夾的網址。Google Auth Platform 應設定相關 scope 及測試使用者。
5. 授權後重整 YouTube，點歷史紀錄的「更新索引」。

## v0.3.5
- 新增 `YouTube Slides/index.json`：只儲存每部影片 ID、標題、資料夾 ID、投影片張數、更新時間；不儲存 PNG 或縮圖。
- 新增同步產生的 `INDEX.md`：可直接在 Google Drive 瀏覽影片名稱、截圖張數及資料夾超連結。
- YouTube 頁面先以既有 localStorage 即時標記縮圖，再以背景小型索引更新跨裝置資料；每個 Chrome 設定檔的雲端讀取最多每 15 分鐘一次，非同步且不下載圖片。
- 歷史紀錄「更新索引」優先讀取單一 `index.json`。第一次沒有索引時進行完整掃描並建立索引；另增「完整修復」按鈕，遇到舊圖/手動變動可重新掃描雲端 PNG 檔名，重建兩份索引。
- PNG 上傳仍即時，成功上傳後約 2 分鐘合併更新兩份索引，以降低 API 呼叫及寫入頻率；失敗保留髒資料標記並重試，不影響原圖同步。
- 保留 IndexedDB 原圖、本機快取、按影片 Lazy Load、影片隱藏 ID、舊格式相容、既有 OAuth 授權及固定套件 ID。
- 雲端索引為可修復的快取快照；多裝置同時寫入或手動刪圖後，可能暫時不一致，使用「完整修復」以雲端圖片為準。未經實際 Chrome 測試前不建議移除舊版資料。

## v0.3.4
- 新增雲端資料夾純標題命名：上傳新影片時，資料夾名稱使用清理後的影片標題，YouTube ID 寫入私有 Google Drive appProperties.youtubeVideoId，不出現在名稱中。
- 雲端讀取、索引、下載與繼續上傳會同時識別舊式影片 ID 資料夾及帶私有 ID 的標題資料夾；既有影片會沿用舊資料夾，避免重複建檔。
- 同標題資料夾會依序加上 (2)、(3) 等可讀尾碼，不顯示影片 ID。檔名最長 108 個 Unicode 字元並移除跨平台不適用字元。影片後續改標題不會反覆更名。
- 在設定頁可預覽舊資料夾，再選擇手動整理：逐一在同一資料夾 ID 上寫入私有 appProperties 並改為標題，不移動、不刪除 PNG，原有雲端圖片 ID 不變。
- 若舊影片缺乏可用標題索引，可手動輸入標題。整理前必須確定本機待同步圖片數量為零。舊版擴充套件不支援新命名方式，因此建議先驗證新版再整理舊資料夾。
- 已有資料夾不會因安裝新版而自動更名。全部圖片與 IndexedDB 均維持原狀。

- 固定擴充套件 ID、Google OAuth 設定、現有資料夾綁定、資料庫、截圖、快速掃描及 ZIP 格式均未變更。
- 須覆蓋原擴充套件資料夾並在 chrome://extensions 重新載入，不可移除套件，以免清除本機未同步資料。

## Alpha 限制
- v0.3.1 已由使用者回報成功登入與同步；v0.3.2 尚待實際 Chrome 端驗證。
- 不會移動或刪除舊版 Drive PNG。刪除功能暫停。
- 本機離線擷取不需要 OAuth；同步需 Google 帳號授權，測試版需列為測試使用者。離線待上傳 PNG 保存在擴充套件 IndexedDB；成功上傳後本機備份仍保留，可能占用磁碟。雲端既有圖片需連線讀取，非全量離線副本。
- 單張傳輸上限 24 MiB（超過須匯出 ZIP）。卸載擴充套件之前請先確定同步完成／匯出備份；同一安裝綁定一個帳號與資料夾。
- 部分歷史索引可能保留在 Drive 外部刪除的項目，以免默默遺失資料。跨裝置索引請按「更新索引」。
- Chrome OAuth token 留在 service worker，沒有外部伺服器。不需 Google Drive 桌面 App、n8n 或 Google Client Secret。不應把 Client Secret 或 token 放進 GitHub。
- Google Cloud 外部 Testing 應用可能需要重新授權。這是未上架的私人測試版本。
