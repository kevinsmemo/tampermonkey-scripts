# YouTube Slides Extractor — Chrome Extension v0.4.0 (Cloud Alpha)

## 安裝與連接

1. 下載此分支 ZIP，解壓縮。停用舊 Tampermonkey 腳本（不要移除資料）。
2. 此測試版已內建專案 OAuth Client ID，不需要 setup.html 或個別設定。Chrome 的 chrome://extensions → 開發人員模式 → 載入未封裝項目 → 選 chrome-extension 資料夾。
3. 如果已載入舊 Alpha，直接覆蓋原擴充套件資料夾中的檔案並按重新載入；不要卸載以免清除離線資料。
4. 點擴充套件圖示或 YouTube 面板「Google Drive 設定」。新資料夾模式僅請求 drive.file；既有資料夾模式需完整 Drive scope 並輸入專用 YouTube Slides 資料夾的網址。Google Auth Platform 應設定相關 scope 及測試使用者。
5. 授權後重整 YouTube，點歷史紀錄的「更新索引」。

## v0.4.0 — 純時間圖片檔名與舊圖遷移
- 新擷取的 PNG 使用 `HH-MM-SS-mmm.png`（例：`00-02-35-770.png`），同一毫秒多張圖時使用 `_02`、`_03` 後綴。檔名只顯示影片播放時間；不含 UUID、`direct/tab`、`quick/normal`。副檔名 `.png` 保留。
- UUID、毫秒數、截圖來源與模式、擷取時間寫入新圖片的 Google Drive `appProperties`；本機 IndexedDB 同樣保留必要 metadata。雲端檔案 ID 仍以 Google Drive 為準。
- 現有 67 張圖片原本沒有單獨的 Drive appProperties；遷移時在各影片資料夾新增 `slides.json`，以不變的 Drive `fileId` 對應原檔名、UUID、來源、模式、影片時間及新檔名。`capturedAt` 原檔未提供，不憑空補造。
- 舊／新兩種檔名都可讀，重新整理 Google Drive 歷史資料時會以 `driveId` 搬移本機索引與已快取的 PNG（如有），避免更名後重複計數。仍保留 `INDEX.md` 表格和 `index.json` 影片層索引。
- 本機已存在同時間檔名時自動分配流水號；雲端上傳時發現同名不同圖片會保留兩張並嘗試後綴更名。Drive 不支援原子唯一檔名，多台裝置極端同時寫入時仍有短暫競爭可能，會以重複名稱檢查／錯誤提示停止危險覆寫。
- 舊圖僅改名、保留原本 Google Drive 檔案 ID 與 PNG bytes，不移動或刪除；一份逐張對照表（`migration-plan.json`）存於版本備份資料夾。尚未安裝 v0.4.0 的裝置應先更新並重新整理 YouTube，避免舊版看不到新檔名。
- 性能：圖片索引仍以本機快取與延遲讀取為主；每部影片只按需讀取對應的 `slides.json`，無需下載全部 PNG 才能還原技術資訊。保留現有 5 分鐘索引合併更新與圖片快取機制。

## v0.3.7
- 將 YouTube 網域 `localStorage` 內的歷史影片張數與標題，安全遷移至擴充套件專用 `chrome.storage.local`，儲存使用每部影片獨立 key，不與其他網站共享。原資料在成功寫入後才刪除；若遷移失敗，保留原資料以供重試。
- 透過 service worker 序列化批次寫入，避免多個 YouTube 分頁同時覆寫整份索引；各分頁使用 `chrome.storage.onChanged` 接收更新。
- 索引更新以 750 ms 批次合併後一次寫入，降低頻繁的 `localStorage` 同步存取及背景訊息數量。更新標題不再觸發整頁縮圖掃描；標記存在檢查改為 O(1) 計數。
- 上傳流程新增每部影片資料夾 ID 的 5 分鐘記憶體快取，重複上傳同部影片時不需反覆查詢資料夾；快取不涉及 PNG 內容，上傳失敗仍保留待傳原圖。
- 保留無須 Google 登入的本機離線模式；新使用者預設使用自己 Google Drive 的專用資料夾（drive.file）。原有使用者授權模式、圖片、索引檔及固定擴充套件 ID 不變。首次設定頁也明確說明 Google 登入為選用。
- Google Drive 根目錄 `index.json` 仍是可修復的快取，不承諾原子多裝置寫入；公開版仍需進一步完成衝突防護及 Chrome Web Store／OAuth 發行流程。

## Alpha 限制
- v0.3.1 已由使用者回報成功登入與同步；v0.3.2 尚待實際 Chrome 端驗證。
- 不會移動或刪除舊版 Drive PNG。刪除功能暫停。
- 本機離線擷取不需要 OAuth；同步需 Google 帳號授權，測試版需列為測試使用者。離線待上傳 PNG 保存在擴充套件 IndexedDB；成功上傳後本機備份仍保留，可能占用磁碟。雲端既有圖片需連線讀取，非全量離線副本。
- 單張傳輸上限 24 MiB（超過須匯出 ZIP）。卸載擴充套件之前請先確定同步完成／匯出備份；同一安裝綁定一個帳號與資料夾。
- 部分歷史索引可能保留在 Drive 外部刪除的項目，以免默默遺失資料。跨裝置索引請按「更新索引」。
- Chrome OAuth token 留在 service worker，沒有外部伺服器。不需 Google Drive 桌面 App、n8n 或 Google Client Secret。不應把 Client Secret 或 token 放進 GitHub。
- Google Cloud 外部 Testing 應用可能需要重新授權。這是未上架的私人測試版本。
