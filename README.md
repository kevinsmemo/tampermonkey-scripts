## YouTube Slides Extractor

[Install in Tampermonkey](https://raw.githubusercontent.com/kevinsmemo/tampermonkey-scripts/main/youtube-slides-extractor.user.js)

Automatically capture stable video frames, deduplicate slides, and export timestamped images, Markdown and JSON as a ZIP. Runs locally in the browser.
